## Шаг 2. Бэкенд (Supabase, паки SQL по порядку)

ПАКЕТ A — роли и деньги:
- profiles: role private|dealer + поля дилера (company_name, logo_url);
  «на площадке с» = created_at.
- transactions (type: topup|bonus|gift|spend|refund; amount numeric(10,2);
  description; created_at). Баланс = СУММА транзакций, не отдельное поле.
- RLS: чтение только своих; insert — только через SECURITY DEFINER RPC.
- RPC: get_balance, get_transactions, credit_gift (админ/подарок),
  spend_balance с проверкой достаточности (под будущие цены).
- Пополнение сейчас = credit_gift вручную; провайдер подключим позже (TODO).

ПАКЕТ B — статистика:
- listing_stats (listing_id unique, views, favorites, contacts).
- RPC track_listing_event(p_listing_id, p_event in ('view','contact'));
  просмотры владельцем НЕ считать.
- Счётчик favorites обновляется триггерами на insert/delete избранного.
- RPC get_my_listings_stats (кабинет продавца), get_unread_count (бейдж чата).

ПАКЕТ C — сохранённые поиски и пуши:
- saved_searches (user_id, filters jsonb, active, created_at).
  Ключи filters: brand, model, price_from/to, year_from/to, city, fuel.
- RPC save_search_from_filters (upsert по хэшу фильтров) — вызывается
  из онбординга и кнопки «Сообщить, когда появится».
- Триггер insert в listings (status=published): совпадение с saved_searches →
  push_queue.
- Триггер update listings.price (снижение): пуш всем, у кого в избранном.
- Триггер insert в messages: пуш получателю.
- push_queue (user_id, title, body, payload jsonb, sent, created_at) + RLS.
- Edge Function (Deno) send-push: читает push_queue.sent=false, шлёт через
  FCM, секреты — Deno.env.get; список требуемых секретов выведи в отчёте.

ПАКЕТ D — продвижение и каталог:
- listings: is_vip bool, boosted_until timestamptz.
- RPC activate_promotion(p_listing_id): проверка владельца; сейчас только
  режим «подарок»; пишет gift-транзакцию; выставляет поля.
- Обновить RPC каталога: выдача сначала активные промо, затем по дате.
- Проверить/добавить нормализацию двуалфавитности (функция нормализации +
  колонки _norm + backfill) и PostGIS-радиус, если отсутствуют.

ПАКЕТ E — deep links:
- RPC каталога/карточки возвращают site_url = https://{домен}/listing/{id}.
- Готовое содержимое apple-app-site-association и assetlinks.json
  под мои домен/bundle из ответов Шага 1.
